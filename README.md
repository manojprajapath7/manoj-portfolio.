UPLOAD TO GITHUB PAGES
1. Create or open your GitHub repository.
2. Upload all four files directly into the repository root (not inside a folder).
3. Make sure the page file is named exactly index.html.
4. Open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for deployment, then open the URL shown in Settings → Pages.

The profile photo is embedded inside index.html, so no separate image file is needed.
